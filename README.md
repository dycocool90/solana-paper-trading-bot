Solana Paper Trading Bot

This is a personal, non-commercial Python project for researching Solana memecoins.

The application runs locally on Windows and uses public market data from DexScreener to monitor tokens and simulate trades using virtual funds only. No real cryptocurrency transactions are made.

Planned Reddit integration

I am requesting read-only access to Reddit's Data API to analyze public discussions about Solana tokens.

The planned integration will:

Monitor mentions of token names and symbols in relevant public subreddits.

Measure changes in discussion activity over time.

Display aggregated community-interest trends in a local research dashboard.

Use Reddit activity as one research signal alongside market data.

The application will not post, comment, vote, send private messages, or interact with Reddit users.

Reddit API access is not yet enabled. The integration is planned and subject to Reddit's approval and applicable policies.
